# Samkok New Force — เว็บจากข้อมูล APK

เว็บไซต์: https://niasmin.github.io/game-build/

รุ่น0.5 เพิ่มคูปองลงลายเซ็นดิจิทัลและแอดมินคูปองบนอุปกรณ์ ดู [วิธีใช้คูปอง](docs/COUPONS.md)

รุ่น0.4 เพิ่มร้านค้ารายวัน ภารกิจ อุปกรณ์ และเพิ่มดาว โดยใช้ข้อมูลและภาพจาก APK:

- หน้าจอแนวตั้ง หน้าเข้าเกม เมือง และเมนู ใช้ภาพเดิม ฟอนต์ Kanit และไอคอนเดิม
- ขุนพล74คนพร้อมภาพที่จับคู่ตาม ID ชื่อไทย ค่าสถานะ และคำอธิบายสกิลต้นฉบับ
- เริ่มด้วยเล่าปี่วัยหนุ่ม จัดทัพได้6ตำแหน่งและย้าย/สลับแถวหน้า-หลังได้ และรับขุนพลจากรางวัลสองด่านแรก
- โหลดข้อมูลเส้นทางด่าน1,837รายการ รางวัลไอเทม และรายการไอเทม4,795รายการ
- อัปเกรดด้วยตารางต้นทุน/ค่าสถานะตามอาชีพและขีดจำกัดดาวที่กู้จากต้นฉบับ
- ขุนพล13คนที่มีไฟล์ครบใน APK มีแอนิเมชันที่แปลงจาก Spine เดิมเป็น PNG sprite sheets
- หน้าขุนพลเต็มจอ แท็บสถานะ/สกิล ตัวกรองขุนพลที่มี และสีคุณภาพจากข้อมูลเดิม
- ทะลวงขั้นตามต้นทุนและเพดานเลเวลเดิม พร้อมย้ายเซฟรุ่นเก่าโดยไม่ลบความคืบหน้า
- เสบียงพักทัพตามอัตราต่อนาทีเดิม สูงสุด12ชั่วโมง เก็บเศษรางวัลระหว่างการรับ
- ไอคอนไอเทมต้นฉบับ190ภาพ คำสั่งใช้เฉพาะ88สูตรคงที่ที่กู้ได้ และรวมชิ้นส่วนขุนพลตามสูตรเดิม
- ระบบทั้งหมดเชื่อมร้านค้า 9 รายการ ภารกิจที่รองรับ 4 รายการ อุปกรณ์ 12 ช่อง และเพิ่มดาวด้วยวัตถุดิบตามเงื่อนไข
- รายละเอียดขอบเขตและข้อจำกัดรุ่นนี้: [EXPANDED_SYSTEMS.md](docs/EXPANDED_SYSTEMS.md)
- เก็บความคืบหน้าเฉพาะเบราว์เซอร์ด้วย `localStorage` key `samkok-web-original-v2` แยกจากต้นแบบเดิม

**ยังไม่ใช่เกมเดิมครบทุกระบบ**: ศัตรู สูตรดาเมจ จังหวะต่อสู้ ทรัพยากรเริ่มต้น และผลคัดขุนพลยังเป็นการจำลองเว็บ การสะสม/มอบรางวัลพักทัพและธุรกรรมไอเทมเป็นบริการจำลองในเซฟเว็บ การคัดขุนพลใช้ต้นทุนต้นฉบับแต่ให้ผลตามลำดับ ไม่ใช่อัตราสุ่มจริง ไม่มีบัญชีเกมเดิม การชำระเงิน ผู้เล่นหลายคน หรือเซิร์ฟเวอร์เดิม

## รันและทดสอบ

ใช้ Node.js24 ไม่ต้องติดตั้ง dependencies:

```sh
npm test
npm start
```

พอร์ตเริ่มต้น3000 ปรับด้วย `PORT` เซิร์ฟเวอร์สำหรับพัฒนาไม่เปิดไฟล์ `.git` หรือโค้ดเซิร์ฟเวอร์

```sh
npm run build
```

ส่งเฉพาะไฟล์ `dist/` ไป static hosting รองรับ path `/game-build/` บน GitHub Pages ทุก asset ใช้ relative paths ซอร์สอยู่ `main` และเว็บอยู่ `gh-pages` การแก้ซอร์สไม่ deploy อัตโนมัติ ต้อง build และอัปเดตชุดเว็บใหม่

## วิธีเล่น

กดเริ่มเกม → ออกศึก → รับรางวัลและขุนพล → ไปหน้าขุนพลเพื่ออัปเกรด/จัดทัพ → ต่อด่านถัดไป กระเป๋าแสดงรายการรางวัลที่มีจริง กดรูปตัวละครมุมบนเพื่อดูข้อมูลหรือลบเซฟหลังยืนยัน
