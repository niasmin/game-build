# สามก๊ก — เส้นทางจอมทัพ (เว็บต้นแบบ)

เกมวางแผนแบบเทิร์นบนเว็บ เล่นคนเดียว มีขุนพล 6 คนให้จัดทีม 3 คน การโจมตี สกิล ฟื้นพลัง ศัตรูตอบโต้ แคมเปญ 5 ด่าน และบันทึกความคืบหน้าในเบราว์เซอร์

นี่คือระบบการเล่นที่เขียนขึ้นใหม่ ไม่ใช่การกู้ซอร์สหรือพอร์ตเกม Android ได้ครบ ไม่เชื่อมต่อบัญชี เซิร์ฟเวอร์ หรือระบบซื้อของของเกมเดิม ภาพบางส่วนสกัดจาก APK เพื่อประกอบต้นแบบ โดยยังไม่ยืนยันตัวตนขุนพลจากภาพ ส่วนที่เหลือเป็นภาพตัวอักษรจาก CSS

ใช้ Node.js 24 ที่มีอยู่แล้ว ไม่ต้องติดตั้ง dependencies:

```bash
cd /workspace/game-build
npm start
```

เซิร์ฟเวอร์ใช้พอร์ต 3000 ปรับได้ด้วย `PORT` ใช้ `npm test` ทดสอบกติกาต่อสู้และข้อมูลบันทึก

วิธีเล่น: เลือกทีมใน “ขุนพลของฉัน” → เข้าศึก → เลือกขุนพล เลือกศัตรู แล้วกดโจมตีหรือสกิล แต่ละคนออกคำสั่งได้ครั้งเดียวต่อรอบ ใช้เล่าปี่ฟื้นพลังทีม สกิลมีคูลดาวน์ 3 รอบ ชนะเพื่อรับทองและเปิดด่านถัดไป ปุ่ม ↻ ลบความคืบหน้าหลังยืนยัน

ข้อมูลเก็บเฉพาะ `localStorage` ของเบราว์เซอร์ ไม่มีบัญชีและการซิงก์ข้ามอุปกรณ์ อย่าล้างข้อมูลเว็บไซต์หากต้องการเก็บความคืบหน้า

รายละเอียดหลักฐานจาก APK และขอบเขตการสร้างใหม่: [docs/RECONSTRUCTION.md](docs/RECONSTRUCTION.md)

## Build และ deploy

รัน `npm test` แล้ว `npm run build` เพื่อสร้างเว็บ static ใน `dist/` โดยไม่รวม APK, เครื่องมือวิเคราะห์, โค้ดเซิร์ฟเวอร์ หรือ Git metadata ใช้ไฟล์ในโฟลเดอร์นี้บน static hosting ได้โดยตรง ทุก asset ใช้ relative path รองรับ GitHub Pages ที่ `/game-build/`

GitHub Pages ใช้ branch `gh-pages` โฟลเดอร์ `/` ส่วนซอร์สโค้ดเก็บใน `main` การเปลี่ยนซอร์สต้อง build และเผยแพร่ `dist/` ใหม่ ไม่ deploy อัตโนมัติ
